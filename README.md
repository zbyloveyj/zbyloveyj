## Research focus / 研究方向

| 研究主题 | 关注的问题 |
| --- | --- |
| **Microbial ecology / 微生物生态** | 大规模宏基因组、生态因子、微生物群落共变与人群异质性 |
| **Brain–gut axis / 脑肠关联** | 精神疾病临床异质性、认知表型与功能脑影像 |
| **Microbial genetics / 微生物遗传** | 微生物遗传变异、水平基因转移和功能重塑 |
| **AI for Biology / 智能生物解析** | 多模态学习、可解释 AI、规范建模与科研智能体 |
