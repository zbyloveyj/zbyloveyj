### 朱宝圆 · Baoyuan Zhu

**华南理工大学博士在读 · 智能生物解析**

我关注微生物生态与脑功能之间的联系，用宏基因组、多组学与可解释计算研究个体和疾病之间的差异。科研之外，我以 **「一心问道」** 写作科学历史小说和开放教材，试着把复杂的科学讲清楚，也走近科学背后的人。

> 在研究中追问，在写作中理解。

## 02 / 研究方向

**微生物生态** · 大规模宏基因组、连续生态因子与群落异质性。  
**脑肠关联** · 精神疾病、临床认知维度与功能脑影像。  
**微生物遗传** · 遗传变异、水平基因转移与功能重塑。  
**智能生物解析** · 多模态整合、可解释学习与规范建模。
